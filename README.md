# Team Rakshak Autopilot Stack

## Overview

Team Rakshak Autopilot Stack is a full-featured autonomous vehicle software framework developed for unmanned aerial systems, intelligent robotics platforms, and field deployment applications.

The software stack supports multiple vehicle architectures including:

* Multirotors
* Fixed-wing aircraft
* Hybrid VTOL systems
* Ground rovers
* Autonomous surface vehicles
* Experimental robotic platforms

The project is designed for reliable autonomous navigation, telemetry communication, mission execution, and onboard system integration.
